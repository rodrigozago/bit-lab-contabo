# 📄 PDFs de Face Lab — Guias por Papel

## ✅ PDFs Criados

Dois guias profissionais em PDF para cada papel/persona do Face Lab:

### 1. 📸 **Face_Lab_Producer_Guide.pdf** (7 KB)

**Para quem**: Fotógrafos e Produtores de Eventos

**Contém**:
- O que é Face Lab (resumo executivo)
- Quem é o Producer (fotógrafo, produtor, organizador)
- 5 Benefícios principais (sem trabalho manual, privacidade, satisfação, etc)
- **Como Começar — 5 Passos** (login → conectar Drive → criar álbum → scan)
- O que acontece depois (convidados se cadastram, faces são encontradas)
- **Dicas Importantes** (6 dicas: compartilhamento, nomes, tempo, privacidade, etc)
- **FAQ — 6 Perguntas Frequentes**:
  - Fotos originais armazenadas?
  - Convidados veem fotos de outros?
  - Re-scan?
  - Tempo de processamento?
  - Convidados pagam?
  - Eventos corporativos?
- Informações de Suporte

**Páginas**: 3 (A4/Carta)
**Formato**: Profissional, colorido, tabelas, bem estruturado

### 2. 👤 **Face_Lab_Guest_Guide.pdf** (9 KB)

**Para quem**: Clientes/Convidados (pessoas que recebem link pra encontrar fotos)

**Contém**:
- O que é Face Lab (resumo para convidado)
- Quem é o Guest (você! Convidado que quer suas fotos)
- **6 Benefícios** (rápido, preciso, privado, sem limite, fácil, download)
- **Como Começar — 5 Passos** (link → login → cadastrar rosto → aguardar → minhas fotos)
- **Cadastrando seu Rosto** (2 opções: webcam ou upload)

- **Vendo suas Fotos** (menu, grid, botões, cores dos quadrados)
- O que acontece quando confirma "Sou eu!" (Face Lab aprende, busca em outros eventos)
- **Dúvidas Comuns — 6 FAQs**:
  - Rosto fica salvo?
  - Outras pessoas veem minhas fotos?
  - Rejeitar pessoa inteira?
  - Fotos são originais?
  - Mobile?
  - Quanto tempo demora?
- **Troubleshooting — 6 Problemas e Soluções**
- Informações de Suporte

**Páginas**: 3 (A4/Carta)
**Formato**: Profissional, colorido, tabelas, bem estruturado

## 🗂️ Como Usar

### Distribuir para Producers
```
1. Abra face-lab/Face_Lab_Producer_Guide.pdf
2. Imprima ou envie por email
3. Producer lê e começa a usar
4. Referência rápida para dúvidas
```

### Distribuir para Guests
```
1. Abra face-lab/Face_Lab_Guest_Guide.pdf
2. Inclua no email de convite (com link do app)
3. Guest lê antes de acessar
4. Troubleshooting integrado
```

### Casos de Uso
- **Onboarding**: Novo producer recebe PDF
- **Email de Convite**: Guest recebe PDF junto com link
- **Documentação**: Inclusão em repositório
- **Suporte**: Link para PDF quando cliente tira dúvida
- **Material de Marketing**: Compartilhar em redes sociais
